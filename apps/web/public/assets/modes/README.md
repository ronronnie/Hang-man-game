# Mode assets

Optional mode-specific backgrounds and future media belong here. Mode mappings,
particle treatments, sound overrides, and UI colors are configured in
`src/assets/mode-assets.ts`.

Expected background locations:

- `i-know-this-game/background.webp`
- `ultra/background.webp`
- `ultra-max/background.webp`

Mode sound effects are optional. Point a mode's `soundEffects` entries at files in
its folder to override the default UI sounds for that mode.
